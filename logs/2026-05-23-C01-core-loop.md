- **验收**:
  - [x] 打开 .md 文件，渲染为 Block[] 列表，含 heading/paragraph/code/quote/list/hr 类型
  - [x] 点击 paragraph/heading → 该块切为 contentEditable，可输入文本
  - [x] 编辑后失焦/点其他块 → 内容通过 sync 回写到 editorStore.content
  - [x] 切换到 Source 模式 → Monaco 显示已编辑的 content
  - [x] 光标在块内编辑 → 重渲染后光标位置不变
  - [x] IME 输入（中文/日文）→ composition 期间不闪屏不丢字
  - [x] 点击代码块 → overlay textarea 编辑原始行，不激活 contentEditable
  - [x] Ctrl+Z 撤销 → 回到上一次编辑前
  - [x] 500ms 内连续输入 → undo 栈只记录一条
- **耗时**: ~1h
- **决策**: 
  - 解析层使用 remark+remark-gfm (现有依赖), 类型桥接绕过 unified 多版本冲突
  - 渲染层 React.memo 以 block.markdown 为比较键，仅 active block 改变时重渲染
  - 代码块使用 textarea overlay 而非 contentEditable (避免 syntax 破坏)
